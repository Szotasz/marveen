# Backup

> Back up Marveen's data with a single command — with WAL checkpoint, retention limit, and a restore guide.

---

## Running the backup

```bash
cd <project-root>
bash scripts/backup.sh
```

Output: `backups/claudeclaw-YYYYmmdd-HHMMSS.tar.gz`

The archive **contains sensitive tokens** (dashboard Bearer, channel bot tokens, `.env` project secrets). The `backups/` directory must be excluded from cloud sync (iCloud, Dropbox, Google Drive).

---

## What is backed up

The archive has two groups so a restore is unambiguous about where each file belongs:

### `repo/` group — extract under the project root

| File / Directory | Description |
|-----------------|-------------|
| `store/claudeclaw.db` (+ `-shm`, `-wal`) | Main SQLite database: memory, kanban, messages, token log |
| `store/.dashboard-token` | Dashboard Bearer token |
| `.env` | Project secrets (API keys, bot tokens) |
| `scheduled-tasks.json` | Legacy schedule file, if present |
| `assets/meetings/**` | Meeting transcripts and memos |
| `agents/*/CLAUDE.md`, `SOUL.md`, `.mcp.json` | Sub-agent identity and MCP configuration |
| `agents/*/.claude/channels/**/.env`, `access.json` | Sub-agent channel tokens and pairing state |

### `home/` group — extract under `$HOME`

| File / Directory | Description |
|-----------------|-------------|
| `~/.claude/skills/**` | The self-built skill library |
| `~/.claude/scheduled-tasks/**` | File-based scheduled tasks (SKILL.md + task-config.json) |
| `~/.claude/channels/*/.env` | Main agent channel token |
| `~/.claude/channels/*/access.json`, `invites.json`, `approved/**` | Paired senders, invites, approvals |
| `~/Library/LaunchAgents/com.<MAIN_AGENT_ID>.*.plist` | launchd job definitions |

### What is NOT included

- `node_modules/`, `dist/` — regenerated by `npm install && npm run build`
- `.venv-whisperx`, `.venv-diar` — platform-specific Python venvs, not portable
- `store/github-repos/` — cloned GitHub repos, can be re-cloned
- Docker volumes (InfluxDB, Grafana) — must be exported separately; see [MIGRATION.md](MIGRATION.md)

## SQLite WAL checkpoint

Before archiving the script runs a WAL checkpoint:

```bash
sqlite3 store/claudeclaw.db 'PRAGMA wal_checkpoint(TRUNCATE);'
```

This ensures the archive is a self-contained, consistent snapshot — not a partial WAL state. If `sqlite3` is not available, the script falls through and copies the files as-is.

---

## Retention limit

The script automatically keeps the **newest 14** archives and prunes the rest:

```
backups/claudeclaw-20260613-070000.tar.gz  ← newest
backups/claudeclaw-20260612-070000.tar.gz
...
backups/claudeclaw-20260531-070000.tar.gz  ← 14th (kept)
backups/claudeclaw-20260530-070000.tar.gz  ← pruned
```

## Verifying the archive

```bash
# Quick overview (MANIFEST.txt + structure)
tar -tzf backups/claudeclaw-20260613-070000.tar.gz | head -20

# Show only the groups and MANIFEST
tar -tzf backups/claudeclaw-20260613-070000.tar.gz \
  | sed -E 's,(^[^/]+/[^/]+/).*,\1...,' | sort -u

# Read the MANIFEST (host, repo root, contents)
tar -xOzf backups/claudeclaw-20260613-070000.tar.gz MANIFEST.txt
```

Expected structure:
```
MANIFEST.txt
repo/store/claudeclaw.db
repo/store/.dashboard-token
repo/.env
home/.claude/skills/...
home/.claude/scheduled-tasks/...
...
```

## Restore (quick)

```bash
# 1. Extract to a temp directory
mkdir -p /tmp/restore
tar -xpzf backups/claudeclaw-20260613-070000.tar.gz -C /tmp/restore

# 2. Review the MANIFEST
cat /tmp/restore/MANIFEST.txt

# 3. repo/ group -> project root
rsync -a /tmp/restore/repo/ <project-root>/

# 4. home/ group -> $HOME
rsync -a /tmp/restore/home/ "$HOME/"
```

For the full restore procedure (machine migration, launchd reload, TCC permissions, Docker volumes) see: [MIGRATION.md](MIGRATION.md).

## Automation

The backup can be run from cron or as a scheduled task:

```bash
# Example: every day at 3:00 AM
0 3 * * * cd <project-root> && bash scripts/backup.sh >> logs/backup.log 2>&1
```

Also triggerable via the dashboard API:

```bash
curl -s -X POST http://localhost:3420/api/backup \
  -H "Authorization: Bearer $(cat store/.dashboard-token)"
```
